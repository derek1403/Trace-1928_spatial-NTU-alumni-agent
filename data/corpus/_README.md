> 底線開頭的檔案（如本檔）**不會**被 `ingest.py` 載入，僅作說明用。

## 為什麼這裡是空的

因為史料還沒查證完成。

本專案的核心主張是「Agent 不編造史實」。如果連語料庫本身都塞入未經查證的內容，
整個主張就自我推翻了。所以在 9/8–9/9 的查證階段完成前，這裡刻意保持空白。

**空語料庫下系統的行為是正確的**：Agent 會對所有具體問題回答「這我倒沒印象」，
而不是編一個答案。這正是 `system_prompt.md` 的 A 類規則在運作。
啟動介面會顯示對應的警示，那是預期行為，不是壞掉。

要測試檢索管線本身，請用 `eval/fixtures/corpus/`（虛構語料，永遠不會被誤認為真實校史）。

## 檔案格式

每個 `.md` 檔開頭一段 frontmatter，之後是正文。正文以**空行分段**，
每段成為一個獨立的檢索 chunk（過短的段落會併入前一段）。

```markdown
---
source: 《國立臺灣大學校訊》第 123 期
source_date: 1955-03-01
landmark: zongtu
era: 1950s
verified: false
verified_by:
---

第一段。這會成為一個 chunk。

第二段。這會成為另一個 chunk。
```

### 欄位

| 欄位 | 必填 | 說明 |
|---|---|---|
| `source` | ✅ | 出處。缺少時仍會載入，但引用會標成「未標註來源」 |
| `source_date` | | 該史料的日期 |
| `landmark` | | `fuzhong` / `zongtu` / `wenxueyuan`，用於限縮檢索 |
| `era` | | 年代標籤，如 `1930s`、`1950s`、`1970s` |
| `verified` | ✅ | 是否經圖書館／校史館館員校對。未校對者 Agent 引用時會保留語氣 |
| `verified_by` | | 校對者 |

## 待蒐集清單

### 傅鐘（1960–70s）

- [ ] 🔴 **傅鐘設立年份與緣由** —— 最高優先
- [ ] 🔴 **「21 響」典故的正確說法與可靠出處** —— 這是使用者最常問的一題，也是 demo 的核心問題。**必須查到可引用的出處，不接受口耳相傳的版本。**
- [ ] 1960–70 年代校園配置與現況的差異
- [ ] 該年代的學生生活細節（非政治性）

### 舊總圖 / 校史館（1950s）

- [ ] 舊總圖落成年份、帝大時期原始用途
- [ ] 1950 年代的閱覽室配置、開放時間、藏書規模
- [ ] 當時文學院的課程結構與考試制度
- [ ] 當時的物價區間 —— **須有明確出處，不可推估**

### 舊文學院（帝大 1930s）

- [ ] 舊文學院落成年份、建築樣式、原始用途配置
- [ ] 臺北帝國大學創校年份與初設學部
- [ ] 文政學部的科系結構
- [ ] 台籍學生在帝大／文政學部的實際比例
- [ ] 當時校園語言使用實況

### 建議來源

- 臺大校史館、臺大圖書館數位典藏
- 《國立臺灣大學校訊》舊刊
- 校友口述歷史紀錄與回憶錄
- 國家圖書館「臺灣記憶」
- 中央研究院「開放博物館」

> **原則**：優先使用當時的人自己寫的一手材料。後世評述帶著詮釋，
> 會把人設變成論文。詳見 `agents/persona_construction_method.md`。
