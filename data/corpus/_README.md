其餘仍待補（見下方清單）。**空白處不要用推測填滿** —— 理由如下。

本專案的核心主張是「Agent 不編造史實」。如果連語料庫本身都塞入未經查證的內容，
整個主張就自我推翻了。**所以這裡只放查到出處的內容，查不到的就留空。**

**語料缺漏時系統的行為是正確的**：Agent 對查不到的具體問題會回答「這我倒沒印象」，
而不是編一個答案。這正是 `system_prompt.md` 的 A 類規則在運作 —— 是設計，不是壞掉。

要測試檢索管線本身（而不依賴真實史料），用 `eval/fixtures/corpus/` 的虛構語料 ——
內容全為架空，永遠不會被誤認為真實校史。

## 檔案格式

每個 `.md` 檔開頭一段 frontmatter，之後是正文。正文以**空行分段**，
每段成為一個獨立的檢索 chunk（過短的段落會併入前一段）。

```markdown
---
source: 《國立臺灣大學校訊》第 123 期
source_date: 1955-03-01
landmark: zongtu
era: 1950s
verified: false
verified_by:
---

第一段。這會成為一個 chunk。

第二段。這會成為另一個 chunk。
```

### 欄位

| 欄位 | 必填 | 說明 |
|---|---|---|
| `source` | ✅ | 出處。缺少時仍會載入，但引用會標成「未標註來源」 |
| `source_date` | | 該史料的日期 |
| `landmark` | | `fuzhong` / `zongtu` / `wenxueyuan`，用於限縮檢索 |
| `era` | | 年代標籤，如 `1930s`、`1950s`、`1970s` |
| `verified` | ✅ | 是否經圖書館／校史館館員校對。未校對者 Agent 引用時會保留語氣 |
| `verified_by` | | 校對者 |
