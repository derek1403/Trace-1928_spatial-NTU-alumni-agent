# 人設建構方法論

> **內部文件。不寫入申請計畫書。**
>
> 原因：對外宣稱依賴第三方 skill 會稀釋自身的技術貢獻。計畫書中應直接陳述人設的**設計原則與倫理界線**，而非引用來源。

---

## 一、問題

「尋跡 1928」的核心是一個可信的歷史人設。但人設很容易做壞，壞法有兩種：

**壞法 A：查資料查出來的殼。** 把年代背景、物價、制度整理成一份設定表塞給模型，結果是一個會背誦史料的導覽機器人。它知道很多事，但不像一個人。

**壞法 B：戲劇化的假人。** 為了「有年代感」而堆砌腔調，每句話都文謅謅、動不動就感慨。這種人設一開始有趣，三輪之後令人厭煩，而且完全不可信。

真正的人設不是設定表，是**一個人在意什麼、怕什麼、對什麼好奇**。

---

## 二、可借鑑的框架

GitHub 上的 [nuwa-skill](https://github.com/alchaincyf/nuwa-skill)（花叔 / alchaincyf）處理的是相近的問題：把一個人的思維方式蒸餾成可執行的 skill。它的三層 pipeline 值得借鑑：

    一手資料  →  心智模型  →  表達 DNA

- **一手資料**：不用二手評述，只用當事人自己產出的材料
- **心智模型**：從材料中萃取此人的決策啟發式——他遇到事情時怎麼想
- **表達 DNA**：他的語言特徵、句式習慣、迴避什麼、偏好什麼

### 但有一個關鍵錯配

**nuwa 吃的是「有大量公開語料的具名公眾人物」。** 我們的主角是「1950 年代的匿名台大學生」——**這個人不存在，沒有語料可蒸餾**。

所以不能直接套用工具，只能借用方法。

## 三、本專案的改造版 pipeline

    群體一手史料  →  時代心智模型  →  個體化表達  →  史實約束層

### 第 1 層：群體一手史料

替換 nuwa 的「個人語料」為「同世代群體的一手材料」：

| 來源 | 用途 |
|---|---|
| 《台大校訊》舊刊 | 當時校方與學生關切的議題、用語 |
| 校友口述歷史紀錄 | 生活細節、語感、記憶的質地 |
| 當時的學生刊物與壁報 | 同儕之間的說話方式 |
| 校友回憶錄與散文 | 個人化的感受與敘事節奏 |
| 校史館既有研究與展覽文字 | 已經過學術把關的史實骨架 |

**原則**：只用當時的人自己寫的東西，避免後世評述——後世評述帶著詮釋，會把人設變成論文。

### 第 2 層：時代心智模型

從材料中萃取的不是「1950 年代發生了什麼」，而是**當時的學生在意什麼、怎麼判斷事情**：

- 稀缺什麼？（座位、書、錢、時間）
- 焦慮什麼？（考試、前途、家裡的期望）
- 什麼事情理所當然到不會被提起？（這些反而是最有價值的細節）
- 對外界的態度是什麼？（好奇？謹慎？疏離？）

**「不會被提起的事」是關鍵。** 一個真的活在那個年代的人，不會特別解釋當時的日常。人設的可信度往往來自於**他把什麼當成不用說的前提**。

### 第 3 層：個體化表達

群體心智模型還不是一個人。加上個體差異，讓他成為特定的某個人：

- 選一個學院（文學院）——決定他的知識邊界與盲點
- 選一組性格特徵（話多、好奇、容易離題）
- 選幾個反覆出現的具體事物（一個常提的同學、一個習慣的座位、一件耿耿於懷的小事）
- 選一個語言指紋（起頭方式、口頭禪、迴避的詞彙）

見 `persona_1950s_literature_student.md`。

### 第 4 層：史實約束層 —— 本專案獨有

nuwa 沒有這一層，因為它蒸餾的人物本來就有明確的公開言論可對照。**我們的虛構人設必須額外加上約束**，否則會變成幻覺產生器。

這一層就是 `system_prompt.md` 的 A 類／B 類分野：

- **B 類（個人敘事）** ← 由第 1–3 層自由生成
- **A 類（史實斷言）** ← 必須經 `retrieve_archive` 檢索、`verify_claim` 驗證

**人設負責「像一個人」，RAG 負責「說的是真的」。兩者在架構上分離。**

## 四、倫理界線

### 為什麼主角必須是虛構的

技術上，用女媧式的方法蒸餾**真實**歷史人物是完全可行的——傅斯年有《傅斯年全集》、演講稿、書信，語料充足且品質高，蒸餾出來的人設會比虛構學生更立體。

**但本專案刻意不這麼做。**

讓 AI 扮演一位真實可考的已故人物說話，有三個無法迴避的問題：

1. **名譽風險**：AI 一旦說錯話，那些話會被歸給一個真實存在過的人
2. **史實爭議**：即使有語料支持，語氣、態度、立場的推測仍是創作，而創作被冠上真名就是虛構歷史
3. **家屬與機構的立場**：未經同意讓 AI 代言已故者，在倫理上站不住腳

### 界線

| 作法 | 允許 |
|---|---|
| 虛構匿名學生作為主角 | ✅ |
| 真實人物作為**引用來源**（「傅校長說過……」，且有出處） | ✅ |
| 虛構人設「聽說過」「遠遠見過」真實人物 | ✅ |
| 讓 AI 以真實人物的**第一人稱**說話 | ❌ 絕對禁止 |
| 替真實人物**推測**未曾記載的言論或態度 | ❌ 絕對禁止 |

此界線已寫入 `system_prompt.md` 的絕對禁令第 4 條。

## 五、驗證方式

人設做得好不好，不能靠自我感覺。三個檢查點：

1. **年代穿幫檢查**：跑一組刻意誘導的提問（問手機、問網路、問當代事件），檢查 Agent 是否維持人設且不編造
2. **史實正確率**：50 題 golden QA 評測集，量測 A 類陳述的 grounded accuracy
3. **人味檢查**：請館員或文史背景者閱讀對話逐字稿，判斷「這像不像一個人在說話」——這項無法自動化，只能靠人

第 3 項是最重要也最容易被跳過的。**一個史實全對但讀起來像維基百科的 Agent，是失敗的。**
